# ZGL Todo List

一个基于 JavaScript/TypeScript 的待办事项管理应用。

## 📖 项目简介

本项目旨在提供一个简洁、高效的待办事项管理工具，支持任务的增删改查、状态标记等功能。前端采用现代 Web 技术栈构建，注重用户体验和代码质量。

## ✨ 主要功能

- [x] 创建新任务
- [x] 标记任务完成/未完成
- [x] 编辑任务内容
- [x] 删除任务
- [x] 任务分类/标签
- [x] 数据本地持久化存储
- [ ] 数据云端存储 (计划中)

## 🛠️ 技术栈

- **语言**: TypeScript / JavaScript
- **框架**: Electron / React
- **构建工具**: Vite
- **包管理器**: pnpm
- **其他依赖**: better-sqlite3 / dayjs
